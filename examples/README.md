# Demo examples

The repository intentionally does not include fabricated "real user voice" files or a
fake 5-minute video. Use the scripts below after configuring API keys to create genuine
examples.

Suggested demo set:

1. `poem_01.txt` — motivational Muktak.
2. `poem_02.txt` — devotional Doha.
3. `voice_01.mp3` — generated with a consented user voice clone.
4. `voice_02.mp3` — second generated poem using the same authorized clone.
5. `video_01.mp4` — 5-minute poem video generated from a user photo + voice audio.
6. `video_02.mp4` — second 5-minute example.

For a 5-minute sample, make the generated poem long enough to produce approximately
5 minutes of speech. The app itself uses the actual audio duration, so the video does
not need a hard-coded five-minute duration.
